CLI 与数据接口

从终端或 AI 代理读取本站公开 JSON 快照。需要 Python 3.9 及以上版本与 Click，无需密钥。直接运行命令进入交互模式；各命令支持 --json 和 --lang zh、zh-hant、en（仅限已有核准字段）。构建时间不代表来源核查时间，空值表示未知；事件文章暂未提供英文。

安装

pipx install https://heronatlas.com/cli/cli_anything_heronatlas-0.1.0-py3-none-any.whl
uv tool install https://heronatlas.com/cli/cli_anything_heronatlas-0.1.0-py3-none-any.whl

示例

cli-anything-heronatlas info --json
cli-anything-heronatlas banks --json
cli-anything-heronatlas statement fed --lang en --json
cli-anything-heronatlas judgments --status 有效 --json
cli-anything-heronatlas calendar --economy us --days 14 --json
