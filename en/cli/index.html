CLI & Data API

Read the public JSON snapshots from your terminal or AI agent. Python 3.9+, Click, no API key. The bare command opens a REPL. Every command supports --json and --lang zh, zh-hant or en where admitted fields exist. Source checks can be older than the build. Null means unknown; English event articles are unavailable.

Install

pipx install https://heronatlas.com/cli/cli_anything_heronatlas-0.1.0-py3-none-any.whl
uv tool install https://heronatlas.com/cli/cli_anything_heronatlas-0.1.0-py3-none-any.whl

Examples

cli-anything-heronatlas info --json
cli-anything-heronatlas banks --json
cli-anything-heronatlas statement fed --lang en --json
cli-anything-heronatlas judgments --lang en --json
cli-anything-heronatlas calendar --economy us --days 14 --json
